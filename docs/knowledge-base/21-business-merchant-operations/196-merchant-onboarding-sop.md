# Merchant Onboarding SOP

**Status:** STABLE — there is no SOP because there is no onboarding. See [`../02-business-workflows/55-merchant-onboarding-workflow.md`](../02-business-workflows/55-merchant-onboarding-workflow.md) for the full explanation.

## What staff should do instead, if someone asks "how do we onboard merchant X"

There is no onboarding action to take. If a specific domain is failing extraction or checkout, the correct response is an engineering task (add/fix a `scrape_config` override), not a business-development onboarding process — route accordingly. See [`../12-operations/40-merchant-vendor-support-sop.md`](../12-operations/40-merchant-vendor-support-sop.md) for that engineering-facing procedure.
