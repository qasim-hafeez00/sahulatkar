# Merchant Settlement Agreement

**Status:** STABLE — not applicable. There is no settlement between SahulatKar and any merchant, so there is no settlement agreement to document. See [`../17-merchant-documentation/72-merchant-settlement-flow.md`](../17-merchant-documentation/72-merchant-settlement-flow.md) for the full explanation (SahulatKar pays merchants in full, immediately, via the VCN — nothing is deferred, so nothing requires a settlement agreement).
