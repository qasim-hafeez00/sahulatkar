# Merchant Acquisition Process

**Status:** STABLE — there is none. See [`../02-business-workflows/55-merchant-onboarding-workflow.md`](../02-business-workflows/55-merchant-onboarding-workflow.md) and [`../17-merchant-documentation/65-merchant-overview.md`](../17-merchant-documentation/65-merchant-overview.md) for the full explanation of why.

## Summary

SahulatKar does not acquire merchants — there is no sales motion, no partnership pipeline, no target-account list, because the vendor-agnostic model requires no merchant participation at all. Any third-party site becomes purchasable the moment a customer pastes its URL, with zero acquisition effort.

## The one place "acquisition" might genuinely apply

If the "affiliate partner" tier (see [`../17-merchant-documentation/75-merchant-commission-fee-model.md`](../17-merchant-documentation/75-merchant-commission-fee-model.md)) represents a real, actively pursued relationship rather than an inherited byproduct of the Rye API integration, then *that* specific tier might have a real acquisition motion behind it — unconfirmed in current documentation. Business Development should resolve this ambiguity (see [`75-merchant-commission-fee-model.md`](../17-merchant-documentation/75-merchant-commission-fee-model.md)) before this document can be meaningfully filled in.

## What this category is really about instead
